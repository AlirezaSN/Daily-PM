# Explain an API to a non-technical stakeholder

## What the interviewer is testing

- Technical communication
- Ability to simplify without becoming inaccurate
- Cross-functional collaboration

## Strong Answer Structure

| Concept | Simple Explanation |
| --- | --- |
| API | A contract that lets two systems exchange information |
| Request | What one system asks for |
| Response | What the other system sends back |
| Reliability | Whether the exchange works consistently |

## Sample Answer Outline

An API is like a menu and ordering system between products. One product asks for a specific thing in an agreed format, and the other returns a predictable response.

## Practice Prompt

Explain a payment API to a sales manager in five sentences.
