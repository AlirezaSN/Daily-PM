# How would you improve activation for a fintech app?

## What the interviewer is testing

- Funnel thinking
- Customer empathy
- Ability to propose experiments

## Strong Answer Structure

| Area | What to Investigate |
| --- | --- |
| Segment | Which users are failing to activate? |
| Step | Where do users drop? |
| Cause | Is it trust, complexity, timing, or value clarity? |
| Experiment | What small change would validate the cause? |

## Sample Answer Outline

I would inspect the activation funnel, segment by acquisition source and user intent, interview recent drop-offs, then test improvements around trust, onboarding clarity, and first-value speed.

## Practice Prompt

Define activation for a banking app in one measurable sentence.
